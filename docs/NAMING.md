# Naming notes

**Decision (2026-10-13): the project is called Yakka** (Australian slang for work, as in "hard yakka"; from Yagara *yaga*). Chosen domain options: yakka.io (free at time of checking) or a prefixed .app domain. Tagline idea: "Share the yakka." Completion message idea: "Onya, {name}!"

## Criteria for the shortlist

- Easy to say aloud and spell from hearing it ("scan the ___ tag").
- A .app domain free (HTTPS-only TLD; fits a PWA), ideally .com as well.
- No clash with chore or to-do apps (TickTick, Tody, Donetick, Chorecast, OurHome).
- Works as a lowercase npm / GHCR / Docker name.
- Short enough to fit in a QR label caption.

## Next step

Run the domain and GitHub check over the unchecked lists, for example:

```sh
for n in tickedoff ticketyboo hoodunit muckin kaji syssla choreus tapstead tapkeep; do
  for t in com app; do
    sleep 0.6
    echo "$n.$t $(curl -s -o /dev/null -w '%{http_code}' -L https://rdap.org/domain/$n.$t)"
  done
done   # 404 = unregistered, 200 = registered, 429 = rate-limited (retry)
```
